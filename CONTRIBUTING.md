# Contributing listings

## Rules

1. **Always open an Issue first** using the Token or DApp template.
2. Wait for a maintainer to label the Issue `approved` (or ask for more info).
3. Only then open a PR that:
   - touches `discover/` and/or `tokens/` only
   - references the Issue (`Closes #123`)
   - does not change workflows, docs maintainer scripts, or unrelated files
4. Do not open PRs against other ZekionProtocol product repositories for listings.

## Review criteria (summary)

- Accurate contract addresses and decimals
- Working HTTPS app URL (DApps)
- Reachable contact / security contact
- Clear test notes (especially testnet)
- No phishing / impersonation of existing brands

Maintainers may reject or delay listings that need protocol or risk review.
